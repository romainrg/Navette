# Navette 0.1 — plan

Status: **approved on 2026-11-10** with [the specification](../specs/0.1.md).

## Rules for every increment

- One branch and one pull request per increment, Conventional Commits. Nothing is pushed, tagged or released, and the GitHub repository is not created, without explicit approval each time.
- Order inside an increment: Core and tests, then the service in `AppEnvironment` (live and demo), then the view.
- Done means: `make test` passes with zero warnings; new strings have French; each new screen has a `make screenshots` scene opened and checked in light, dark and French; `CHANGELOG.md` (Unreleased) and docs are updated; the PR lists the manual tests for the author.
- Tests never trigger a permission prompt and never drive the UI.

## Phase A — spikes (throwaway, before any interface)

Each spike lives on a `spike/*` branch that is never merged. Its only deliverable on `main` is a findings note in `docs/spikes/`. **The author reviews the findings before phase C starts.**

### S1. System SSH, askpass, SFTP v3

A command-line Swift package plus a helper executable, against a user-mode `sshd` on a high port (temporary host key and `authorized_keys`, no system setting touched).

Questions to answer:

1. Does `ssh -s -- host sftp` over pipes complete INIT/VERSION and a full `OPENDIR`/`READDIR`/`CLOSE`? Which extensions does the macOS server advertise?
2. Askpass: with `SSH_ASKPASS_REQUIRE=force`, what exactly does the helper receive (text, `SSH_ASKPASS_PROMPT`) for an unknown host key, a key passphrase, a wrong passphrase retry? How are yes/no answers returned? Does it work from a hardened-runtime, ad hoc signed app bundle?
3. What does `ssh` print and return for a changed host key, an unreachable host, a refused authentication?
4. Control socket: does a private `ControlPath` under the temporary directory fit the socket path limit, and does a second channel open without a second authentication?
5. Throughput of pipelined reads and writes on a 1 GB file compared with `/usr/bin/sftp`.

Pass: 1 and 2 work. If not, stop and bring alternatives to the author; no dependency is added.

Not coverable locally (listed as manual tests for the author): password and one-time-code prompts against a real server, FIDO keys, 1Password and Secretive agents, `ProxyJump`.

### S2. FTPS with TLS session reuse

A command-line Swift package against `vsftpd` with `require_ssl_reuse=YES` (needs spec Q7).

1. Explicit TLS with Network.framework: plain greeting, `AUTH TLS`, TLS inserted on the live connection.
2. Data connection after `PROT P` and `EPSV`: does the server accept it as a resumed session? With TLS 1.2 and with TLS 1.3?
3. If reuse fails: what can be controlled, and what the options cost.

Pass: `MLSD` and a `RETR` succeed with reuse enforced. Otherwise report options and wait.

### S3. Keychain and ad hoc signing (half a day at most)

Store a password from one ad hoc build, read it from a rebuilt one. Record exactly what macOS asks. Feeds spec Q6.

## Phase B — project foundation

Does not depend on the spikes and can be reviewed while they run.

### 1. Project documentation and tooling

- `AGENTS.md` (commands, map, the invariants of the spec, conventions, definition of done) and `CLAUDE.md` importing it.
- `README.md` and `README.fr.md` (same sections), `CONTRIBUTING.md`, `SECURITY.md`, `docs/ARCHITECTURE.md` (skeleton), `docs/RELEASING.md`, issue and PR templates.
- Screenshot tool (`Tools/Screenshots`, `scripts/screenshots.sh`, `NavetteScreenshots` target, `make screenshots`), app icon (`scripts/make-icon.swift`).
- `make integration` and `scripts/integration-servers.sh` (start and stop the local servers).
- Verify: `make test`, `make screenshots` renders the welcome placeholder.

## Phase C — implementation

### 2. Core foundations

`RemotePath` (raw bytes, display, normalized comparison), `RemoteItem`, `RemoteFileSystem` and `Capabilities`, `InMemoryFileSystem` with latency and fault injection, connection URL parser, `Bookmark` model and JSON store.
Tests: hostile names (spaces, quotes, emoji, NFC/NFD pairs, invalid UTF-8), URL forms, store round-trip, in-memory driver contract. The contract suite is written once and reused by every driver.

### 3. SFTP driver

Packet codec, client with request ids and pipelining, `SSHProcess` launcher (argument array, `--`), `ssh -G` parser, askpass wire protocol and prompt classifier, error mapping from `ssh` output.
Tests: codec on captured packets, classifier on the prompts recorded by S1, argument construction. Integration: the driver contract suite against user-mode `sshd`.

### 4. App shell and connection

Theme ported from Mopster with protocol tints, `AppEnvironment` live and demo, window with sidebar, tabs and welcome state, bookmark tree (folders, colors, drag to reorder), recents, connection sheet with resolved SSH values and Test, Quick Connect (⌘K), askpass helper target and prompt sheets, Keychain credential store, changed-host-key screen.
Scenes: welcome, sidebar, connection sheet per protocol, each prompt sheet.
`scripts/build-release.sh` signs the helper with the same ad hoc settings.

### 5. Browser, list view

Navigation (history, up, go to path), sortable columns, filter, hidden files, selection, new folder, inline rename, remote delete with enumeration and confirmation sheet, context menu, activity log window.
Core: `RecursiveEnumerator` (never follows symlinks, survives loops and unreadable folders), `DeletionPlan` (deletes only what was listed).
Scenes: list, filtered list, delete confirmation, empty folder, error state.

### 6. Transfer engine

Queue, concurrency, pause/resume/retry/cancel, conflict policies, temporary names and rename, verification, resume rules, rate limit, bounded buffers, Trash for replaced local files.
Tests: the full list of spec section 6, all on `InMemoryFileSystem` and temporary directories. Integration: 1 GB round trip and an interrupted-then-resumed transfer over SFTP.

### 7. Transfers drawer and commands

Upload (open panel) and download (default folder) commands, drawer, conflict sheet, transfer settings.
Scenes: drawer with active, paused, failed and finished rows; conflict sheet; settings.

### 8. Drag and drop

Finder to Navette (upload), Navette to Finder (file promises), within the browser (move, with confirmation when it overwrites).
Mostly manual tests; Core covers move planning.

### 9. Inspector and chmod

Inspector sidebar, permission grid and octal field, recursive apply, symlink target, copy URL.
Core: `PermissionSet` conversions, recursive chmod plan. Scenes per protocol capability set.

### 10. Quick Look and Open With

Preview cache, size threshold, edit sessions with folder-level watching, upload on save, remote-changed check, cleanup on tab close, editor settings.
Core: `EditSession` state machine tested on temporary directories.

### 11. FTP and FTPS driver

Shaped by S2. Control channel, reply parser, `MLSD` and `LIST` parsers (Unix, DOS), passive modes, TLS, resume, certificate sheet and per-bookmark trust.
Tests: parsers on fixtures, reply parser, command sequencing against a scripted fake control channel. Integration: contract suite against `vsftpd`.

### 12. WebDAV driver

PROPFIND parser, operations, authentication, TLS trust, Nextcloud and ownCloud presets, temporary name then `MOVE`.
Tests: XML fixtures from Apache, Nextcloud and ownCloud, URL escaping. Integration: contract suite against user-mode `httpd` with `mod_dav`.

### 13. Column view

Finder-style columns with preview, sharing selection, drag and menu logic with the list. May slip to 0.1.1 (spec Q3).

### 14. Release preparation

README screenshots in both languages, complete `docs/ARCHITECTURE.md`, changelog for 0.1.0, full manual test checklist for the author, universal build check (`make release`). **No tag, push or release without explicit approval.**
